# MarkdownGlance 0.1.3

The Full Screen toggle is Ctrl+Shift+V again (Cmd+Shift+V on macOS).

0.1.2 moved it to the Ctrl+K, Shift+V chord to leave Sublime Text's Paste and
Indent alone. That chord never fired — the palette shows it, pressing it does
nothing — so the key comes back. Paste and Indent is shadowed while a Markdown
source view or a preview is focused; Ctrl+K, Ctrl+V still pastes from history,
and you can drop the binding here:

    Preferences -> Package Settings -> MarkdownGlance -> Key Bindings
