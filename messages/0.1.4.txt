# MarkdownGlance 0.1.4

Housekeeping for the Package Control submission. Nothing you press changes.

The Settings item in the menu and the palette now call Sublime Text's own
edit_settings command directly instead of going through a package command, so
they behave like every other package's settings entry. If you bound anything to
mdglance_open_settings, that command is gone; call edit_settings with

    "base_file": "${packages}/MarkdownGlance/MarkdownGlance.sublime-settings"

The bundled copy of markdown2 no longer carries its command-line entry point,
which a Sublime Text package never runs. Rendering is unchanged.
