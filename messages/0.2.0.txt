# MarkdownGlance 0.2.0

An outline of the Markdown source, on Ctrl+Shift+B (Cmd+Shift+B on macOS) or
"MarkdownGlance: Toggle Outline" in the command palette.

It lists the headings as they are written in the buffer — # markers, raw text,
indented by level — in a group of its own beside the file. The entry holding
the caret is highlighted and follows it, the list re-scans as you type, and
clicking an entry moves the caret to that heading and centres it. No preview
has to be open, and the file never has to have rendered: this reads the buffer,
not the rendered document, which is what separates it from the table of
contents inside the preview. That TOC is unchanged.

The key toggles the way Zed's outline panel does: open and focus, focus if it
is already open, close on a press from inside it.

One Sublime Text default changes, and only in Markdown. Ctrl+Shift+B is
Build With…, and this binding applies while a Markdown source view or an
outline this package created is focused; plain Ctrl+B is untouched everywhere.
Markdown has no build system. To keep the key, delete that entry from
Preferences → Package Settings → MarkdownGlance → Key Bindings — the command
stays in the command palette without it.

ADR 0010 in the repository records the decision and the measured defaults.
