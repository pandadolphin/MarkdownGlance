# MarkdownGlance 0.2.1

Documentation only. No code, no settings and no key bindings change, and
rendering is byte-for-byte what 0.2.0 produced.

The README now opens with a screenshot of the preview — the Mermaid diagram,
an aligned table and the table of contents in the group beside it — and the
outline screenshot shows the outline reading the project's own README. The
images live under docs/, which is excluded from the package you installed.

If you are arriving from 0.1.x, the feature to try is the outline of the
Markdown source: Ctrl+Shift+B, or Cmd+Shift+B on macOS.
