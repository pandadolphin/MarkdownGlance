# MarkdownGlance 0.1.2

The Full Screen toggle moved from Ctrl+Shift+V to Ctrl+K, Shift+V
(Cmd+K, Shift+V on macOS).

Ctrl+Shift+V is Sublime Text's own Paste and Indent, and the old binding took
it over in exactly the buffers where you would reach for it. Nothing else
changed. The old shortcut still works if you keep it in your own key bindings:

    Preferences -> Package Settings -> MarkdownGlance -> Key Bindings
