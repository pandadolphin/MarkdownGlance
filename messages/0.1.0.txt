# MarkdownGlance 0.1.0

- Adds same-window Side-by-Side and Full Screen live Markdown preview.
- Adds native TOC navigation, per-session zoom and theme-aware styling.
- Loads local and bounded asynchronous remote images.
- Supports opt-in Mermaid rendering; diagram source is sent to the configured
  server only when enabled.

This is an independent package. Its default shortcuts overlap
MarkdownLivePreview during coexistence; see `docs/migration.md`.
