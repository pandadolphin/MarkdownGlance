# MarkdownGlance 0.3.1

Documentation only. No code, no settings and no key bindings change, and
rendering is byte-for-byte what 0.3.0 produced.

Installing by hand no longer assumes you use Git. The README now spells out
the other route: download the source ZIP from the latest release, unzip it,
rename the folder from MarkdownGlance-0.3.1 to MarkdownGlance -- the name has
to be exact -- and move it into the directory Preferences > Browse Packages...
opens. Restart Sublime Text and the preview is there.

The Package Control submission is still pending, and the README says so rather
than leaving you to find out from the channel.

The feature to try is still the one 0.3.0 shipped: enable_toc, off by default,
which puts a navigable table of contents in the group beside the preview.
